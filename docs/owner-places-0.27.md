# Места владельцам: перенос на Алулу 0.27 (пакет alula 0.27.0)

Зачем: `tools/migrate-alula-227.py` переносит файлы 2.26 на 0.27 механически; что механически не решается, он печатает местом
(`файл:строка: вид: что сделать`, выход 1). Здесь — места, которые скрипт называет на наборах машин и образцах, с владельцем и действием,
и место самого пакета. Набор правят его владельцы в своих репозиториях; пакет их файлов не правит (задача 245, поток П2).
Критерий: `scripts/accept-245.sh` — каждое место скрипта должно быть названо строкой ниже (имя файла, вид места и тип в одной строке).

Проверено 2026-10-28 на копиях наборов во временной папке:
набор методики (crew-harness `machines/methodology`) — скрипт переносит 528 файлов, мест 3, `alula test` — 514 из 514;
набор продукта (crew-harness `machines/product`) — 86 файлов, мест 0, 81 из 81; examples и `spec/samples` 2.26 (e69d729) — 94 файла, место 1, перенос равен дереву.
Набор методики в `ai-dev-methodology/alula-machines` (508 тестов) — те же места; с файлом машины «Совещание» рядом
(`spec/samples/meeting-definitions.alula.md`) `cycle_check` собирается и набор проходит 508 из 508.
