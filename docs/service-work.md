# Сторона сервиса: рабочая запись

- Основание: владелец, 2026-10-29, чат Методики: «согласен, делай супер быстро»; после обсуждения — «Отдельный service (Recommended)», затем утверждение показанного контракта «Утвердить (Recommended)».
- T = 25 мин. Принято, когда: русская и английская записи сервиса дают одно дерево, проверки отвергают неверные объявления, исполнитель отправляет запрос и принимает только относящийся к нему типизированный результат; существующие виды сторон не меняют поведения.
- База: `03c1800`, кандидат 253, не принятый выпуск. Работа изолирована в `feature/service-party`; ветка 253, её дерево, метки и публикация не изменяются. Перед слиянием требуется синхронизация с принятой базой и независимая проверка.
- Вне объёма: сетевые адаптеры, авторизация, подписки, автоматические повторы внешней операции, гарантия однократного эффекта, изменение версии выпуска.
- Проверки и результаты будут записаны после прогона; наличие примера не означает наличие реального адаптера.
- Красная проба до реализации: `nova test src/machine_text/service_test.nv --timeout 600` — RUN-FAIL, положительные проверки `service bilingual` и `service roundtrip`: «вид стороны: agent, human, enhanced, gatekeeper, free_input, machine». Первый запуск выявил ошибку шапки нового примера; она исправлена до этой содержательной красной пробы.
- Внутренний тип строки в JSON — `text`, а в английском исходнике — `str`; первая версия нового JSON-теста ошибочно использовала `str`, исправлено. После добавления слова ожидаемое число строк словаря изменено с 221 на 222; список исторических JSON-имён образцов не менялся.
- Независимый просмотр дерева `180c7ad0a2395c5d665d39f5dce5ab44218e5d8c`: ВЕРНУТЬ — один тест считал заголовок отдельно от 222 записей, но ожидал 222 строки вместо 223. Исправлено; дополнены проверки неверного типа результата и повторного ответа после восстановления состояния ожидания.
- Сборка `nova build src/alula.nv -o target/alula.exe` — успешно. Собранный CLI компилирует русский и английский примеры сервиса в побайтово одинаковые деревья; `target/alula.exe test examples` — `105 of 105 tests passed`.
- Стражи с настроенным `NOVA_STD_PATH`: `bash scripts/guards/run-all.sh --ci` — «ок 5, пропущено 0, FAIL 0». `python tools/check-alula-keywords.py --glossary <словарь методики> --selftest` — 222 записи, 16 видов, 0 расхождений.
- Жду полный прогон `nova test src --jobs 2 --timeout 600`, оценка 10 минут; это прогон, а не отсутствие нового факта. Если он успел скомпилировать прежние тесты до исправления счётчика строк, затронутые модули будут перепроверены после его завершения.
- Полный прогон завершился: 18 групп PASS, 2 RUN-FAIL, 1 SKIP (`src/examples/data`: нет тестов и точки входа, компиляция успешна). Падения: старый скомпилированный счётчик 222 вместо 223 и три неверные границы новых тестов — корреляция запросов проверялась у интерпретатора, а не движка; неизвестный тип искали в ошибках транслятора, а не загрузчика; пояснение отказа искали в сводке, которая выводит только код. Проверки перенесены на правильные границы, не удалены. Производственный код после первого полного прогона не менялся.
- Повтор целиком `nova test src/machine_run src/machine_text --jobs 2 --timeout 600` — `PASS: 2 FAIL: 0`. Таким образом, проверены все 20 исполняемых групп пакета; это полный прогон плюс перепроверка двух исправленных групп, а не второй полный прогон с нуля. Новые тесты: 5 переводчика, 4 загрузчика, 7 исполнения; сценарий движка проверяет чужой и повторный ответ.
- Собранным CLI отдельно выполнен четырёхшаговый сценарий корреляции: ожидание `external-1`, отбрасывание `other-1`, приём результата `external-1`, отбрасывание повторного результата — `ok`. JSON сценария находится в игнорируемом `target/service-correlation.alula.test.json`; это локальная проба, не реальный сервис.
- По добавленным строкам diff проверены шаблоны секретов, персональные пути и символ замены повреждённой кодировки: совпадений нет; `git diff --cached --check` — без замечаний.
- Малый маршрут не уложился в цель 10 минут: один полный прогон включает 20 исполняемых групп с компиляциями до 110 секунд каждая, затем перепроверены две группы. Безопасность внешнего эффекта и настоящий сетевой адаптер не проверялись и не заявляются.
