## Дефект и факты

Симптом (survey `spikes/env/README.md`, пункт 129, переоткрыт 2026-11-15): в слитом юните пакета прямой
вызов метода типа другого модуля **с конструктором в аргументе** выдаёт аргументы в C как `void*` — C не
собирается; тот же резолвер при равной арности может выбрать **не тот** метод (в пробе:
`h.submit_json(envelope)` резолвится в `describe_json`).

- Минимальный носитель на Nova — **зелёный**; на реальном коде Алулы — **воспроизводит** (слово владельца
  2026-11-19). Поэтому строка не ждёт фикса Oracle: решение о форме кода — на стороне пакета.
- Свидетельство: проба `host_contract` (результат F); форма-триггер — `@engine.submit_event(Incoming.incoming(...), …)`.
- Текущие обходы (класс 129a) в пакете:
  - `src/host_contract/contract.nv:174` — `ORACLE-WORKAROUND(129)`: событие в типизированную локальную,
    метод движка — через свободную функцию `submit_admission` (`src/engine/engine.nv`);
  - `src/host_contract/contract.nv:251`, `src/host_contract/contract_test.nv:29` — те же формы в текстах;
  - `src/engine/types.nv:87` — структурный обход: типизированный контракт значений вынесен в отдельный
    модуль `src/machine_typed/` (один модуль — один юнит).

## Что решаем (объём — согласовать до кода)

1. Инвентаризация всех обходов класса 129a в пакете: место, форма вызова, причина, действует ли она на 0.1.6.
2. Решение по каждому: снять обход (если форма больше не ломает сборку — доказать красной пробой на
   0.1.6) либо оставить и зафиксировать правило формы вызова пакета:
   - операции над дескриптором — свободными функциями (`handle`-операции не методами);
   - конструктор в аргументе вызова метода — только через типизированную локальную.
3. Если правило остаётся — держать его пробой (минимальный носитель-красный на 0.1.6) и/или стражем,
   чтобы новый код не заводил запрещённую форму молча.
4. Поведение и публичные API пакета не меняются; формат языка, реестр и 13 сигнатур — вне объёма.

Вне объёма: правки `nv-lang/nova` (Oracle), формат/версия языка, машины и фикстуры методики, релиз и теги.
