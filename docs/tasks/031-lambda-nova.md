# Задача 031: лямбда в форме Новы `|x| выр` (формат 0.31)

- Тип: ломающая языковая правка пакета `nova-alula` + синхронная миграция методики.
- Статус: **реализована 2026-11-19, гейты зелёные; кандидат `733ea75`; ждёт независимой приёмки.** Слово владельца 2026-11-19 (чат методики, после аудита причин): «лямбду Алулы
  свести к форме Новы `|…|`»; карточка методики 123 (`5bede13`).
- Причина: прежняя запись `x => выр` выбрана в 2.18 с двумя отрицательными доводами, отозванными
  владельцем как не объективные: (1) экранирование `\|` в ячейках уже оплачено наборами литералов с 2.5;
  (2) перегрузка знака `|` в Нове не мешает, роли различимы синтаксически. Положительный довод (один
  `=>` с телом/выбор) — стилистический; владелец выбрал симметрию с Новой.

## Что меняется

| Место | Было | Стало |
|---|---|---|
| Лямбда одноместная | `x => выр` | `\|x\| выр` (в ячейке — `\|x\|`, в блоке кода — `\|x\|`) |
| Лямбда двухместная | `(a, b) => выр` | `\|a, b\| выр` |
| Ненужный параметр | `_` | `_` (без изменений) |
| Тело-блок | `x => { … }` | `\|x\| { … }` |
| Формат | 0.30 | 0.31 (файл/дерево 0.30 отвергается с подсказкой `tools/migrate-alula-231.py`) |

Не меняются: узел дерева `lambda` {params, body} и провод `machine/2` целиком (меняется только значение
`alula_version` в деревьях), 13 сигнатур инструментов, реестр, шов 2.25 (2.25-тексты читаются и рендерятся
в прежней форме — паритет хешей тестов).
