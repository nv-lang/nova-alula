# Эпик 019: переход Алулы с 0.28.0 на 0.29.0

**Тип: эпик. Статус: проект, не поручение на реализацию.** База — `de4be0f`; принятые контракты не перепроектируются. До принятия эпика владельцем дочерние задачи не создаются и реализация не начинается. [План, карточки и AC](plan.md), [доказательства подготовки](evidence.md).

## Цель и границы

Перевести исполняемый пакет `0.28.0` к целевой `0.29.0` так, чтобы заявленная поддержка профиля имела runtime-доказательства, а не только модельные тесты. Не обещать exactly-once внешних эффектов, production-аутентификацию, конкретное долговечное хранилище или готовность host-продукта. Сетевые адаптеры и интеграция с host-продуктом не входят по умолчанию.

`0.29.0-alpha.1` — первый prerelease для проверки согласованного, ограниченного набора runtime-возможностей, не production-допуск. `0.29.0` — итоговый выпуск после завершения выбранного scope и явного решения владельца. Условия достаточности и открытые решения — в плане; отсутствие capability не скрывается номером версии.

## Уже сделано — не планировать повторно

- 016: модель открытий/кандидатов и терминология событий; модельные проверки, не runtime.
- 017: typed canonical bytes, digest, строгая manifest projection и vectors; `tools/typed_value_codec.py` — модель encoder, не runtime и не decoder conformance.
- 018: текстовая граница call/event lifecycle и различие `machine_version` (строка/equality) и `revision` (int) в Методике, commit `4be589d84b73058581abfa614e54b55a14cbb40e`, по передаче интегратора 2026-11-01. Mapping/совместимость и runtime/codec не добавлялись, пункт 20 и glossary/hash не менялись. Этой фиксации не должно быть в `de4be0f` другого репозитория; повторно её не планировать.
- База Алулы уже содержит модели профилей и событий. Возвращаться к принятым контрактам можно только для исправления конкретного обнаруженного противоречия/дефекта с пробой, а не ради повторного проектирования.

## Краткое обследование

[README](../../README.md) описывает `0.28.0` и модули `src/engine`, `src/machine`, `src/machine_run`, `src/alula_cli`. `src/machine/value.nv` имеет dynamic `Value` без отдельного optional и прежние `$` tags; `src/machine_run/machine.nv` сохраняет состояние через этот codec. `src/machine_run/accepts.nv` проверяет возможность сигнала по имени, не новый event admission; `src/engine/engine.nv` закрывает terminal reply request до шага машины — это основание обязательной runtime-пробы неверного reply, не уже воспроизведённый дефект. `src/machine_text/lang.nv` допускает 2.25/0.28; `src/machine_table/check.nv` включает семантическую проверку для 0.28: одного version bump недостаточно.

[Контракт codec](../../spec/alula-value-codec.md) отмечает отличия `Value` JSON от typed profile и отсутствие доказанного runtime roundtrip `-0.0`. [Протокол событий](../../spec/alula-event-protocol.md) отмечает отсутствие экспорта manifest и runtime conformance; [engine README](../../src/engine/README.md) описывает только in-memory handlers пакета, настоящие handlers принадлежат хозяину. Модельные доказательства не засчитываются как runtime-проверка. История обследования моделей — [event-lifecycle-work.md](../event-lifecycle-work.md), описание профилей — [interaction-profiles.md](../interaction-profiles.md).
