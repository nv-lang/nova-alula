# Машина: Вызывающая

- machine: caller
- machine_version: 1
- format: 2.25

Родитель пробной пары (задача 119): одна сторона вида `machine`, вызываемая машина `callee` (`callee.alula.md`). Вход вызова — запись `CallInput`: метку и число даёт таблица «Вход» состояния, профиль — столбец «профиль» таблицы «Стороны» (запрос несёт его полем `profile`). Ответ ребёнка — запись `CallOutput`; отказ ребёнка (любой код) родитель записывает и кончает отказом. Фрагмент «Пауза» подключён со списком вложенных `[callee]`: «стоп», «продолжить», «остановить» и «отмена» человека идут вложенной машине сигналом (`передать`), её запрос при паузе остаётся открытым (`отменить_открытые(кроме: вложенные)`).

## Типы

```
тип КодСбоя перечисление
  | НетРезультата = "no_result"
  | ОтказМодели = "model_refused"
  | СоединениеОборвалось = "connection_lost"
  | ФормаНеИсправлена = "form_not_fixed"
  | НетОтветаВСрок = "timeout"
  | ОстановленоЧеловеком = "stopped_by_human"
  | ПотолокЗаходов = "ceiling_reached"
  | ОтмененоРодителем = "cancelled"
  | ПредельТокенов = "max_tokens"
  | ПредельЗапросовХода = "max_turn_requests"
тип CallInput { label строка, count число>=0, profile строка }
тип CallOutput { answer строка, score число>=0 }
```

## Имена

| имя | JSON-имя |
|---|---|
| ВЫЗОВ | Call |
| КОНЕЦ | Done |
| ОТКАЗ | Failed |

## Вход

| имя | тип | примечание |
|---|---|---|
| task | строка | задание: метка вызова |

## Данные

| имя | тип | начальное | не убывает | пишет |
|---|---|---|---|---|
| task | строка | вход.task | — | действия |
| child_result | ?CallOutput | пусто | — | действия |
| child_code | строка | "" | — | действия |
| остановка | "" \| "pause_halt" \| "cancel_request" | "" | — | действия и фрагмент |
| child_attempt | число>=0 | 0 | да | механика |
| enhanced_attempt | число>=0 | 0 | да | механика |

## Стороны

| имя | идентификатор | вид | профиль | сигналы | счётчик |
|---|---|---|---|---|---|
| child | callee | machine callee(вход CallInput, итог CallOutput) | "fast" | — | child_attempt |
| усиленный | enhanced | enhanced(итог ИсходВорот) | — | продолжить { слово_человека строка, автор строка, источник строка }, остановить | enhanced_attempt |

- Предел запросов: 1

## Подключения

```
Пауза(сигнал_остановки: остановить, код_остановки: "pause_halt", вложенные: [callee], отмена_запросов: механика, вход_заново: ничего, право_записи: "родитель ничего не пишет")
```

## Состояния

Начальное состояние: ВЫЗОВ

### ВЫЗОВ — обращение
- Сторона: child
- Запрос:

| поле запроса | выражение | читает |
|---|---|---|
| label | task | сторона |
| count | 3 | сторона |

| № | Событие | Условие | Действия | Куда |
|---|---|---|---|---|
| 1 | ответ(итог) | — | child_result = итог; журнал("child_answered", answer: итог.answer, score: строка(итог.score)) | КОНЕЦ |
| 2 | сбой(причина) | — | child_code = строка(причина); журнал("child_failed", code: строка(причина)) | ОТКАЗ |

### КОНЕЦ — конец
- Читает: child_result

### ОТКАЗ — конец
- Читает: child_code

### ОСТАНОВЛЕНО — конец
- Читает: остановка
- Кроме: остановка в [""]

### ОШИБКА — конец
- Читает: все_данные
- При входе:
  - журнал(запись_перехода);
  - журнал(все_данные)

## Концы

- Результат: строка

| конец | № | когда | ответ |
|---|---|---|---|
| КОНЕЦ | 1 | истина | Ответ(обязательно(child_result).answer) |
| ОТКАЗ | 1 | истина | Отказ(КодСбоя.НетРезультата, child_code) |
| ОШИБКА | 1 | истина | Отказ(КодСбоя.НетРезультата, "дефект вызывающей машины") |
| ОСТАНОВЛЕНО | 1 | остановка == "pause_halt" | Отказ(КодСбоя.ОстановленоЧеловеком, остановка) |
| ОСТАНОВЛЕНО | 2 | остановка == "cancel_request" | Отказ(КодСбоя.ОтмененоРодителем, остановка) |
