# Машина: Запуск сессии

- machine: session_start
- machine_version: 1
- format: 2.22

Запуск одной сессии агента (задача 121): ворота профиля и цены В2, проверка объёма ОБЪЁМ и ворота В1, вызов вложенной машины «Шаг агента» в состоянии СЕССИЯ, разбор итога сессии РАЗБОР_ИТОГА и ворота сбоя В13_СЕССИЯ. Это таблица методики (`task-runner-session-states.md`, десять состояний) в Алуле; «Шаг агента» (`agent_step.alula.txt`) вызывается стороной вида `machine`, фрагмент «Пауза» передаёт ему «стоп», «продолжить», «остановить» и «отмену». Вызывают эту машину «Раннер» и «Проверка цикла» (задача 123); профиль запуска, сборка промпта, измерение объёма, чтение артефакта сессии и остановка группы процессов агента — примитивы хозяина (`standard_registry()`), у которых в продукте пока исполнитель для тестов (`ScriptedHost`). Текст отказа вложенной машины (`текст_отказа`) движок в событие «сбой» не передаёт, поэтому данное остаётся пустым, как в рукописном автомате методики.

Профиль агента уходит вызываемой машине столбцом «профиль» этой таблицы (поле `профиль` её входа), остальные поля `ЗапросАгента` — строки таблицы «Вход» состояния СЕССИЯ. Вратарь — человек по умолчанию, агент по настройке проекта `исполнитель_повышенного_внимания`; усиленный — сторона состояния ПАУЗА.

  - журнал(все_данные)
