# Машина: Веер

- machine: fan
- machine_version: 1
- format: 2.14

Набор вложенных вызовов (задача 119): по запросу к `callee` на каждый идентификатор из входа `order` («линзы» совещания), не больше `LIMIT` одновременно (`Предел запросов`). Каждый элемент набора считает свои попытки в записи `lenses[элемент].attempt` (счётчик `lenses[*].attempt`), запрос — `<элемент>-<попытка>`. Ответ или отказ элемента записывается в `answered` или `lost`, развилка JOIN возвращает в обращение, пока не ответили все. Стороны, которым запрос ещё не ушёл, лежат в `to_send`; после паузы (фрагмент «Пауза» со списком вложенных `[callee]`, `вход_заново: запросы_из_к_отправке`) они уходят из `to_send`.

## Типы

```
перечисление КодСбоя (FailCode) = НетРезультата (NoResult) "no_result" | ОтказМодели (ModelRefused) "model_refused" | СоединениеОборвалось (ConnectionLost) "connection_lost"
                     | ФормаНеИсправлена (FormNotFixed) "form_not_fixed" | НетОтветаВСрок (Timeout) "timeout" | ОстановленоЧеловеком (StoppedByHuman) "stopped_by_human"
                     | ПотолокЗаходов (CeilingReached) "ceiling_reached" | ОтмененоРодителем (Cancelled) "cancelled" | ПредельТокенов (MaxTokens) "max_tokens"
                     | ПредельЗапросовХода (MaxTurnRequests) "max_turn_requests"
тип Lens { name текст, attempt число>=0 }
тип LensInput { label текст, count число>=0, profile текст }
тип CallOutput { answer текст, score число>=0 }
```

## Состояния

Начальное состояние: ПОДГОТОВКА

### ПОДГОТОВКА — операция (Prepare)
- Читает: order

| № | Событие | Условие | Действия | Куда |
|---|---|---|---|---|
| 1 | сразу | — | to_send = order | ЛИНЗЫ |

### ЛИНЗЫ — обращение (Lenses)
- Сторона: lens; набор: order
- Запрос:

| поле запроса | выражение | читает |
|---|---|---|
| label | сторона | сторона |
| count | 1 | сторона |
| answered | answered | исполнитель |
| lost | lost | исполнитель |

| № | Событие | Условие | Действия | Куда |
|---|---|---|---|---|
| 1 | ответ(итог) | — | answered += [сторона]; журнал(lens_answered, party: сторона, answer: итог.answer) | СВОД |
| 2 | сбой(причина) | — | lost += [сторона]; журнал(lens_lost, party: сторона, code: текст(причина)) | СВОД |

### СВОД — развилка (Join)
- Читает: answered, lost, order

| № | Условие | Действия | Куда |
|---|---|---|---|
| 1 | длина(answered) + длина(lost) >= длина(order) | — | КОНЕЦ |
| 2 | иначе | — | ЛИНЗЫ |

### КОНЕЦ — конец (Done)
- Читает: answered, lost

### ОСТАНОВЛЕНО — конец (Halted)
- Читает: остановка
- Кроме: остановка in {""}

### ОШИБКА — конец (Errored)
- Читает: все_данные
- При входе:
  - журнал(запись_перехода);
  - журнал(все_данные)

## Концы

- Результат: []текст

| конец | № | когда | ответ |
|---|---|---|---|
| КОНЕЦ | 1 | истина | Ответ(answered) |
| ОШИБКА | 1 | истина | Отказ(КодСбоя.НетРезультата, "дефект веера") |
| ОСТАНОВЛЕНО | 1 | остановка == "pause_halt" | Отказ(КодСбоя.ОстановленоЧеловеком, остановка) |
| ОСТАНОВЛЕНО | 2 | остановка == "cancel_request" | Отказ(КодСбоя.ОтмененоРодителем, остановка) |
