# Машина: Вызывающая

- machine: caller
- machine_version: 1
- format: 2.14

Родитель пробной пары (задача 119): одна сторона вида `machine`, вызываемая машина `callee` (`callee.alula.md`). Вход вызова — запись `CallInput`: метку и число даёт таблица «Вход» состояния, профиль — столбец «профиль» таблицы «Стороны» (запрос несёт его полем `profile`). Ответ ребёнка — запись `CallOutput`; отказ ребёнка (любой код) родитель записывает и кончает отказом. Фрагмент «Пауза» подключён со списком вложенных `[callee]`: «стоп», «продолжить», «остановить» и «отмена» человека идут вложенной машине сигналом (`передать`), её запрос при паузе остаётся открытым (`отменить_открытые(кроме: вложенные)`).

## Типы

```
тип CallInput { label текст, count число≥0, profile текст }
тип CallOutput { answer текст, score число≥0 }
```

## Вход

| имя | тип | примечание |
|---|---|---|
| task | текст | задание: метка вызова |

## Данные

| имя | тип | начальное | не убывает | пишет |
|---|---|---|---|---|
| task | текст | вход.task | — | строки |
| child_result | ?CallOutput | пусто | — | строки |
| child_code | текст | "" | — | строки |
| остановка | "" \| "pause_halt" \| "cancel_request" | "" | — | строки и фрагмент |
| child_attempt | число≥0 | 0 | да | механика |
| enhanced_attempt | число≥0 | 0 | да | механика |

## Стороны

| имя | идентификатор | вид | профиль | слова ворот | счётчик |
|---|---|---|---|---|---|
| child | callee | machine callee(вход CallInput, итог CallOutput) | "fast" | — | child_attempt |
| усиленный | enhanced | enhanced(итог ИсходВорот) | — | продолжить(слово_человека текст, автор текст, источник текст), остановить | enhanced_attempt |

- Предел запросов: 1

## Подключения

```
Пауза(слово_остановки: остановить, код_остановки: "pause_halt", вложенные: [callee], отмена_запросов: механика, вход_заново: ничего, право_записи: "родитель ничего не пишет")
```

## Состояния

Начальное состояние: ВЫЗОВ

### ВЫЗОВ — обращение (Call)
- Сторона: child
- Срок тишины: —
- Вход:

| поле запроса | выражение | читает |
|---|---|---|
| label | task | сторона |
| count | 3 | сторона |

| № | Событие | Условие | Действия | Куда |
|---|---|---|---|---|
| 1 | ответ(итог) | — | child_result = итог; журнал(child_answered, answer: итог.answer, score: текст(итог.score)) | КОНЕЦ |
| 2 | сбой(причина) | — | child_code = текст(причина); журнал(child_failed, code: текст(причина)) | ОТКАЗ |

### КОНЕЦ — конец (Done)
- Вход: child_result

### ОТКАЗ — конец (Failed)
- Вход: child_code

### ОСТАНОВЛЕНО — конец (Halted)
- Вход: остановка
- Кроме: остановка ∈ {""}

### ОШИБКА — конец (Errored)
- Вход: все_данные
- При входе:
  - журнал(запись_перехода);
  - журнал(все_данные)
