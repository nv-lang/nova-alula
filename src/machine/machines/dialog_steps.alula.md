# Машина: Диалог по шагам

- machine: dialog_steps
- machine_version: 1
- format: 2.22

Многооборотная сессия чата, которая на каждое сообщение пользователя вызывает «Шаг агента» (`agent_step.alula.txt`) как вложенную машину (задача 119, пара «чат + шаг агента»). Сессия ждёт слово человека `сообщение_пользователя(текст)`, собирает запрос агента (запись `ЗапросАгента`; поля её — поля входа вызываемой машины, профиль идёт столбцом «Стороны») и зовёт вложенную машину стороной `шаг` (идентификатор `call`: запросы `call-1`, `call-2`, …); ответ шага (`ОтветАгента`) и отказ записываются, сессия возвращается к ожиданию. `закрыть_сессию` кончает сессию. Первый запрос агента сессия берёт из входа без изменений: так сценарии «Шага агента» (`agent-step-*`) прогоняются через вложенный вызов и дают то же состояние, данные, журнал и очередь, что без него (`src/machine_nested_eq`). Фрагмент «Пауза» подключён со списком вложенных `[шаг_агента]`: стоп, продолжить и остановить человека идут шагу сигналами.


## Имена

## Вход

| имя | тип | примечание |
|---|---|---|
| вид | ВидВызывающего | вид вызывающего первого шага |
| профиль | ПрофильАгента | профиль агента |
| сессия | строка | сессия агента |
| вид_диалога | строка | вид диалога |
| контекст | строка | контекст первого хода |
| пределы | ПределыАгента | пределы шага |
| трасса | строка | трасса вызывающего |
| номер_шага | число | номер шага вызывающего |

Поля входа — ровно поля `ЗапросАгента`, как у вызываемой машины «Шаг агента» (формат 2.12, раздел 1, AL-30); запись `запрос_агента` целиком собирает `начальное`.

## Данные

| имя | тип | начальное | не убывает | пишет |
|---|---|---|---|---|
| запрос_агента | ЗапросАгента | ЗапросАгента { вид: вход.вид, профиль: вход.профиль, сессия: вход.сессия, вид_диалога: вход.вид_диалога, контекст: вход.контекст, пределы: вход.пределы, трасса: вход.трасса, номер_шага: вход.номер_шага } | — | строки |
| step_reply | ?ОтветАгента | пусто | — | строки |
| код_отказа | строка | "" | — | строки |
| число_ходов | число>=0 | 0 | да | строки |
| остановка | "" \| "pause_halt" \| "cancel_request" | "" | — | строки и фрагмент |
| попытка_шага | число>=0 | 0 | да | механика |
| попытка_пользователя | число>=0 | 0 | да | механика |
| попытка_усиленного | число>=0 | 0 | да | механика |

## Стороны

| имя | идентификатор | вид | профиль | сигналы | счётчик |
|---|---|---|---|---|---|
| шаг | call | machine шаг_агента(вход ЗапросАгента, итог ОтветАгента) | запрос_агента.профиль | — | попытка_шага |
| пользователь | user | human(итог ИсходВорот) | — | сообщение_пользователя { текст строка }, закрыть_сессию | попытка_пользователя |
| усиленный | enhanced | enhanced(итог ИсходВорот) | — | продолжить { слово_человека строка, автор строка, источник строка }, остановить | попытка_усиленного |

- Предел запросов: 1

## Подключения

```
Пауза(сигнал_остановки: остановить, код_остановки: "pause_halt", вложенные: [шаг_агента], отмена_запросов: механика, вход_заново: ничего, право_записи: "сессия ничего не пишет")
```

## Состояния

Начальное состояние: ХОД

### ХОД — обращение
- Сторона: шаг
- Запрос:

| поле запроса | выражение | читает |
|---|---|---|
| вид | запрос_агента.вид | сторона |
| сессия | запрос_агента.сессия | сторона |
| вид_диалога | запрос_агента.вид_диалога | сторона |
| контекст | запрос_агента.контекст | сторона |
| пределы | запрос_агента.пределы | сторона |
| трасса | запрос_агента.трасса | сторона |
| номер_шага | запрос_агента.номер_шага | сторона |

| № | Событие | Условие | Действия | Куда |
|---|---|---|---|---|
| 1 | ответ(итог) | — | step_reply = итог; код_отказа = ""; число_ходов += 1; журнал(turn_answered, session: итог.использование.сессия) | ЖДУ |
| 2 | сбой(причина) | — | код_отказа = строка(причина); число_ходов += 1; журнал(turn_refused, code: строка(причина)) | ЖДУ |

### ЖДУ — обращение
- Сторона: пользователь
- Запрос:

| поле запроса | выражение | читает |
|---|---|---|
| запрос_агента | — | исполнитель |

| № | Событие | Условие | Действия | Куда |
|---|---|---|---|---|
| 1 | сигнал(сообщение_пользователя { текст: сообщение }) | — | запрос_агента = { ...запрос_агента, контекст: сообщение }; журнал(user_message, text: сообщение) | ХОД |
| 2 | сигнал(закрыть_сессию) | — | журнал(session_closed) | КОНЕЦ |

### КОНЕЦ — конец
- Читает: число_ходов

### ОСТАНОВЛЕНО — конец
- Читает: остановка
- Кроме: остановка в [""]

### ОШИБКА — конец
- Читает: все_данные
- При входе:
  - журнал(запись_перехода);
  - журнал(все_данные)

## Концы

- Результат: строка

| конец | № | когда | ответ |
|---|---|---|---|
| КОНЕЦ | 1 | истина | Ответ("closed") |
