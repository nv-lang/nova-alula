# Машина: Вызываемая

- machine: callee
- machine_version: 1
- format: 2.12

Вызываемая машина пробной пары «родитель + ребёнок» (задача 119): получает метку и число, спрашивает агента и отвечает записью `CallOutput` (текст агента и число из входа). Родитель — `caller.portolan.md` (одна сторона `machine`) и `fan.portolan.md` (набор сторон). Срок тишины — у запроса к агенту (параметр `ASK_TERM`): у самого вызова машины срока нет (правило 35, пункт 5), когда агент молчит, ребёнок кончает отказом `НетОтветаВСрок`, и родитель получает сбой. Фрагмент «Пауза» принимает сигналы родителя («стоп от родителя», «продолжить от родителя», «остановить от родителя», «отмена запроса») и слова человека.

## Типы

```
тип CallOutput { answer текст, score число≥0 }
```

## Параметры

| имя | тип | по умолчанию | переопределение проектом |
|---|---|---|---|
| ASK_TERM | число≥0 | 5000 | проект.срок_ребёнка |

## Вход

| имя | тип | примечание |
|---|---|---|
| label | текст | метка вызова: подсказка агенту |
| count | число≥0 | число, которое вернётся в ответе |
| profile | текст | профиль стороны, который родитель берёт из столбца «профиль» |

## Данные

| имя | тип | начальное | не убывает | пишет |
|---|---|---|---|---|
| label | текст | вход.label | — | строки |
| count | число≥0 | вход.count | — | строки |
| profile | текст | вход.profile | — | строки |
| agent_text | ?текст | пусто | — | строки |
| остановка | "" \| "no_answer" \| "failed" \| "pause_halt" \| "cancel_request" | "" | — | строки и фрагмент |
| agent_attempt | число≥0 | 0 | да | механика |
| enhanced_attempt | число≥0 | 0 | да | механика |

## Стороны

| имя | идентификатор | вид | профиль | слова ворот | счётчик |
|---|---|---|---|---|---|
| agent | agent | agent(итог текст) | — | — | agent_attempt |
| усиленный | enhanced | enhanced(итог ИсходВорот) | — | продолжить(слово_человека текст, автор текст, источник текст), остановить | enhanced_attempt |

- Предел запросов: 1

## Подключения

```
Пауза(слово_остановки: остановить, код_остановки: "pause_halt", вложенные: [], отмена_запросов: механика, вход_заново: ничего, право_записи: "ребёнок ничего не пишет")
```

## Состояния

Начальное состояние: ЗАПРОС

### ЗАПРОС — обращение (Ask)
- Сторона: agent
- Срок тишины: ASK_TERM
- Вход:

| поле запроса | выражение | читает |
|---|---|---|
| prompt | label | сторона |
| profile | profile | исполнитель |
| count | count | исполнитель |

| № | Событие | Условие | Действия | Куда |
|---|---|---|---|---|
| 1 | ответ(текст_ответа) | — | agent_text = текст_ответа; журнал(callee_answered, label: label) | КОНЕЦ |
| 2 | сбой(причина ∈ {КодСбоя.НетОтветаВСрок}) | — | остановка = "no_answer"; журнал(callee_silent, label: label) | ОСТАНОВЛЕНО |
| 3 | сбой(причина) | — | остановка = "failed"; журнал(callee_failed, reason: текст(причина)) | ОСТАНОВЛЕНО |

### КОНЕЦ — конец (Done)
- Вход: agent_text, count

### ОСТАНОВЛЕНО — конец (Halted)
- Вход: остановка
- Кроме: остановка ∈ {""}

### ОШИБКА — конец (Errored)
- Вход: все_данные
- При входе:
  - журнал(запись_перехода);
  - журнал(все_данные)

## Концы

- Результат: CallOutput

| конец | № | когда | ответ |
|---|---|---|---|
| КОНЕЦ | 1 | истина | Ответ(CallOutput { answer: обязательно(agent_text), score: count }) |
| ОШИБКА | 1 | истина | Отказ(КодСбоя.НетРезультата, "дефект вызываемой машины") |
| ОСТАНОВЛЕНО | 1 | остановка == "no_answer" | Отказ(КодСбоя.НетОтветаВСрок, остановка) |
| ОСТАНОВЛЕНО | 2 | остановка == "failed" | Отказ(КодСбоя.НетРезультата, остановка) |
| ОСТАНОВЛЕНО | 3 | остановка == "pause_halt" | Отказ(КодСбоя.ОстановленоЧеловеком, остановка) |
| ОСТАНОВЛЕНО | 4 | остановка == "cancel_request" | Отказ(КодСбоя.ОтмененоРодителем, остановка) |
