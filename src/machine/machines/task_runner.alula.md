# Машина: Раннер задачи

- machine: task_runner
- machine_version: 1
- format: 2.14

Машина «Раннер задачи» методики (задача 123): фазы РАЗБОР, ПЛАН, РЕАЛИЗАЦИЯ, СДАЧА, ОБРАТНАЯ_СВЯЗЬ и ворота между ними, маршруты «полный» и «быстрый». Это таблицы состояний методики (`task-runner-states.md`, 75 состояний) в Алуле 2.12; журнальные коды и параметры — таблица журнала методики. Машина вызывает вложенные машины «Запуск сессии» (`session_start`, задача 121) и «Проверка цикла» (`cycle_check`, задача 122); «Запуск сессии» в свою очередь вызывает «Шаг агента» — это второй уровень вложенности (прогонщик пары задачи 123 рекурсивный). Сигналы «стоп», «продолжить», «остановить» и «отмена» идут вложенным фрагментом «Пауза». Всё, что у методики «делает исполнитель» (чтение и запись документов задачи, подготовка, блокировка, остановка группы процессов агента, показ человеку), записано примитивами хозяина (`standard_registry()`) с тестовым исполнителем `ScriptedHost`; боевых исполнителей нет.

**Что записано иначе, чем в первоисточнике, и почему** (полный перечень — в разборе задачи). Статус документа, стоп-слово и признаки документа читают примитивы `specification`, `task_plan` и `implementation_report` в «При входе» развилки (по правилу AL-29 чтение — только через `пусть`), а не условие. Внешний объект «утверждения[документ]» — словарь данных: его пишут ЗАПИСЬ_УТВЕРЖДЕНИЯ и КОПИЯ_ПОСТАНОВКИ, снимают операции «снятие»; «утверждение действует» — хеш записи равен хешу документа сейчас. Коды сессий — латинские коды рукописного автомата (`s1`, `s1_fix`, …), метки продолжения и слова остановки — наборы литералов его слов. Слова ворот, у которых в первоисточнике разный состав данных при одном имени («продолжить», «реализация»), записаны с одним составом: слово человека — с автором и источником. Подготовка при возобновлении (`возврат_подготовки`) — действие исполнителя до входа в сохранённое состояние: данное пишет только оно.

## Определения

```
определение новый_цикл() -> Цикл = Цикл { номер_захода: 1, заход_отсчёта: 1, серия_чистых: 0, без_проб_подряд: 0 }

определение документ_по_имени(имя Документ, спец ДокументЗадачи, план ДокументЗадачи) -> ДокументЗадачи =
  если имя == Документ.Спецификация то спец иначе план

определение утверждение_действует(запись ?Утверждение, документ ДокументЗадачи) -> да/нет =
  есть(запись) и обязательно(запись).хеш == документ.хеш

определение дописать_как_факт(текст_файла текст, ответ текст) -> текст =
  текст_файла + "\nFACT: " + ответ

определение через_запятую(имена []текст) -> текст =
  свёртка(имена, "", (накоплено, имя) → если накоплено == "" то имя иначе накоплено + ", " + имя)

определение ранг_риска(риск Риск) -> число≥0 =
  выбор риск { Риск.Низкий → 0; Риск.Средний → 1; Риск.Высокий → 2; иначе → 3 }

определение риск_выше(риск Риск, допустимый Риск) -> да/нет =
  ранг_риска(риск) > ранг_риска(допустимый)

определение признаки_неполны(п ?ПризнакиМаршрута) -> да/нет =
  обязательно(п).цель == "" или не есть(обязательно(п).число_источников) или не есть(обязательно(п).число_частей) или обязательно(п).риск == Риск.НеОценён или обязательно(п).необратимо == Оценка.НеОценено или обязательно(п).причина_известна == Оценка.НеОценено или обязательно(п).касается_нормы == Оценка.НеОценено

определение перечень_неполных_признаков(п ?ПризнакиМаршрута) -> текст =
  через_запятую(фильтр([если обязательно(п).цель == "" то "goal" иначе "", если не есть(обязательно(п).число_источников) то "sources" иначе "", если не есть(обязательно(п).число_частей) то "parts" иначе "", если обязательно(п).риск == Риск.НеОценён то "risk" иначе "", если обязательно(п).необратимо == Оценка.НеОценено то "irreversible" иначе "", если обязательно(п).причина_известна == Оценка.НеОценено то "cause_known" иначе "", если обязательно(п).касается_нормы == Оценка.НеОценено то "touches_norm" иначе ""], имя → имя != ""))

определение признаки_за_порогом(п ?ПризнакиМаршрута, пороги ПорогиМаршрута) -> []текст =
  фильтр([если (обязательно(п).число_источников ?? 0) > пороги.максимум_источников то "sources" иначе "", если (обязательно(п).число_частей ?? 0) > пороги.максимум_частей то "parts" иначе "", если риск_выше(обязательно(п).риск, пороги.допустимый_риск) то "risk" иначе "", если обязательно(п).необратимо == Оценка.Подтверждено то "irreversible" иначе "", если обязательно(п).причина_известна == Оценка.Опровергнуто то "cause_known" иначе "", если обязательно(п).касается_нормы == Оценка.Подтверждено то "touches_norm" иначе ""], имя → имя != "")

определение признак_выходит_за_порог(п ?ПризнакиМаршрута, пороги ПорогиМаршрута) -> да/нет =
  длина(признаки_за_порогом(п, пороги)) > 0

определение параметры_допустимы(п ПараметрыМаршрута) -> да/нет =
  п.чистых_подряд >= МИНИМУМ_ЧИСТЫХ_ПОДРЯД и п.проб_в_чистом >= МИНИМУМ_ПРОБ_В_ЧИСТОМ и длина(п.ослабления) == 0

определение причина_отказа_настроек(п ПараметрыМаршрута) -> текст =
  свёртка(фильтр([если п.чистых_подряд < МИНИМУМ_ЧИСТЫХ_ПОДРЯД то "чистых заходов подряд меньше минимума" иначе "", если п.проб_в_чистом < МИНИМУМ_ПРОБ_В_ЧИСТОМ то "проб в чистом заходе меньше минимума" иначе "", "названо ослабление инварианта"], причина → причина != ""), "", (первая, причина) → если первая == "" то причина иначе первая)
```
