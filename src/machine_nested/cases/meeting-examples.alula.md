# Машина: Примеры совещания

- machine: MeetingExamples
- machine_version: 1
- format: 2.14

Примеры формата 2.14 из пилота «Совещание», в которых есть всё, что вложенные машины добавляют к языку: сторона вида `machine` с разбором и профилем, набор сторон со счётчиком элементов `линзы[*].попытка`
и `Предел запросов`, свойство `Правит`, `Возвратов формы`, подключение фрагмента «Пауза» с непустым списком вложенных машин и `вход_заново: запросы_из_к_отправке`, действия `передать`
и `отменить_открытые(кроме: …)` (из фрагмента). Файл ничего не изображает целиком: это набор конструкций, который переводчик, проверки и обратный генератор обязаны пройти без замечаний.
Примеры изменены против спецификации там, где пилоты нельзя записать как есть: типы вызываемой машины объявлены здесь, `Вход` стороны `machine` называет все поля её типа `вход` (кроме `профиль`), поля
`вид_диалога` и `пределы` добавлены.

## Типы

```
перечисление КодСбоя (FailCode) = НетРезультата (NoResult) "no_result" | ОтказМодели (ModelRefused) "model_refused" | СоединениеОборвалось (ConnectionLost) "connection_lost"
                     | ФормаНеИсправлена (FormNotFixed) "form_not_fixed" | НетОтветаВСрок (Timeout) "timeout" | ОстановленоЧеловеком (StoppedByHuman) "stopped_by_human"
                     | ПотолокЗаходов (CeilingReached) "ceiling_reached" | ОтмененоРодителем (Cancelled) "cancelled" | ПредельТокенов (MaxTokens) "max_tokens"
                     | ПредельЗапросовХода (MaxTurnRequests) "max_turn_requests"
перечисление ВидВызывающего (CallerKind) = Линза (Lens) | СессияЦикла (CycleSession) | ХодЧата (ChatTurn) | Вратарь (Gatekeeper)
перечисление Критичность (Severity) = Критическая (Critical) | Значимая (Significant) | Желательная (Desirable)
тип МодельАгента (AgentModel) { идентификатор (id) текст, поставщик (provider) текст, вариант (variant) ?текст }
тип Токены (TokenUsage) { вход (input) ?число, выход (output) ?число, рассуждение (reasoning) ?число, кэш_чтение (cache_read) ?число, кэш_запись (cache_write) ?число }
тип ПрофильАгента (AgentProfile) { семья (family) текст, модель (model) текст, усилие (effort) ?текст }
тип ПределыАгента (AgentLimits) { срок_тишины (silence_term) ?число, бюджет_токенов (token_budget) ?число, бюджет_стоимости (cost_budget) ?дробное, предел_ходов (turn_limit) ?число }
тип ЗапросАгента (AgentRequest) { вид (kind) ВидВызывающего, профиль (profile) ПрофильАгента, сессия (session) текст, вид_диалога (dialog_kind) текст, контекст (context) текст,
                   пределы (limits) ПределыАгента, трасса (trace) текст, номер_шага (step) число }
тип Использование (Usage) { сессия (session) текст, результат (result) текст, семья (family) текст, модель (model) МодельАгента, токены (tokens) Токены, стоимость (cost) ?дробное,
                    создано (created) число, обновлено (updated) число, занято_контекста (context_used) ?число, трасса (trace) текст, номер_шага (step) число }
тип ОтветАгента (AgentReply) { текст (text) ?текст, артефакт (artifact) ?текст, использование (usage) Использование, начало_запроса (request_started) ?число }
тип Находка (Finding) { критичность (severity) Критичность, доказательство (evidence) текст, повтор (repeat) да/нет, вопрос (question) да/нет }
тип Линза (Lens) { идентификатор (id) текст, потери_подряд (lost) число>=0, пробы (probes) число>=0, попытка (attempt) число>=0 }
тип ИтогЛинзы (LensResult) { находки (findings) []Находка, пробы (probes) число>=0 }
вариант КонтекстРоли (RoleContext) {
  Линза (Lens) { предложение (proposal) текст, ответы_свидетеля (witness_answers) ?[]ОтветСвидетеля }
}
вариант ОтветСвидетеля (WitnessAnswer) {
  СУтверждением (Answered) { утверждение (statement) текст }
  НеИзмерено (NotMeasured) { утверждение (statement) текст }
}
вариант ИтогПравки (EditResult) {
  Закончена (Done) { предложение (proposal) текст }
  Вопрос (Question) { предложение (proposal) текст, вопрос (question) текст }
}
```

## Состояния

Начальное состояние: ПРАВКА

### ЛИНЗЫ — обращение (Lenses)
- Сторона: линза; набор: порядок_линз
- Срок тишины: 0
- Запрос:

| поле запроса | выражение | читает |
|---|---|---|
| вид | ВидВызывающего.Линза | сторона |
| сессия | сторона | сторона |
| вид_диалога | "main" | сторона |
| контекст | вызвать(контекст_роли, КонтекстРоли.Линза { предложение: предложение, ответы_свидетеля: ответы_свидетеля[номер_захода] }) | сторона |
| пределы | ПределыАгента { срок_тишины: пусто, бюджет_токенов: пусто, бюджет_стоимости: пусто, предел_ходов: пусто } | сторона |
| трасса | трасса | сторона |
| номер_шага | номер_шага | сторона |
| номер_захода | номер_захода | исполнитель |
| к_отправке | к_отправке | исполнитель |
| линзы | линзы | исполнитель |
| ответившие | ответившие | исполнитель |

- При приёме:

| событие | действия |
|---|---|
| ответ(итог) | пусть л = обязательно(линзы[сторона]) в (линзы[сторона] = { ...л, потери_подряд: 0, пробы: итог.пробы }); ответившие += 1; находки_линзы[(сторона, номер_захода)] = итог.находки |
| сбой | пусть л = обязательно(линзы[сторона]) в (линзы[сторона] = { ...л, потери_подряд: л.потери_подряд + 1, пробы: 0 }) |

| № | Событие | Условие | Действия | Куда |
|---|---|---|---|---|
| 1 | ответ | — | — | КОНЕЦ |
| 2 | сбой | — | — | КОНЕЦ |

### ПРАВКА — обращение (AuthorFix)
- Сторона: автор
- Срок тишины: 0
- Правит: предложение; проверка: предложение_менялось_с_начала_попытки
- Возвратов формы: 2
- Запрос:

| поле запроса | выражение | читает |
|---|---|---|
| вид | ВидВызывающего.СессияЦикла | сторона |
| сессия | "author" | сторона |
| вид_диалога | "main" | сторона |
| контекст | вызвать(контекст_роли, КонтекстРоли.Линза { предложение: предложение, ответы_свидетеля: пусто }) | сторона |
| пределы | ПределыАгента { срок_тишины: пусто, бюджет_токенов: пусто, бюджет_стоимости: пусто, предел_ходов: пусто } | сторона |
| трасса | трасса | сторона |
| номер_шага | номер_шага | сторона |

- При приёме:

| событие | действия |
|---|---|

| № | Событие | Условие | Действия | Куда |
|---|---|---|---|---|
| 1 | ответ: Закончена | — | указание_автору = "" | КОНЕЦ |
| 2 | ответ: Вопрос | — | указание_автору = "" | КОНЕЦ |
| 3 | сбой | — | — | КОНЕЦ |

### КОНЕЦ — конец (End)
- Читает: предложение

### ОСТАНОВЛЕНО — конец (Halted)
- Читает: остановка
- Кроме: остановка in {""}

- Результат: текст
