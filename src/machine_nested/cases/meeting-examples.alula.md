# Машина: Примеры совещания

- machine: MeetingExamples
- machine_version: 1
- format: 2.23

Примеры формата 2.14 из пилота «Совещание», в которых есть всё, что вложенные машины добавляют к языку: сторона вида `machine` с разбором и профилем, набор сторон со счётчиком элементов `линзы[*].попытка`
и `Предел запросов`, свойство `Правит`, `Возвратов формы`, подключение фрагмента «Пауза» с непустым списком вложенных машин и `вход_заново: запросы_из_к_отправке`, действия `передать`
и `отменить_открытые(кроме: …)` (из фрагмента). Файл ничего не изображает целиком: это набор конструкций, который переводчик, проверки и обратный генератор обязаны пройти без замечаний.
Примеры изменены против спецификации там, где пилоты нельзя записать как есть: типы вызываемой машины объявлены здесь, `Вход` стороны `machine` называет все поля её типа `вход` (кроме `профиль`), поля
`вид_диалога` и `пределы` добавлены.

## Типы

```
тип КодСбоя перечисление
  | НетРезультата = "no_result"
  | ОтказМодели = "model_refused"
  | СоединениеОборвалось = "connection_lost"
  | ФормаНеИсправлена = "form_not_fixed"
  | НетОтветаВСрок = "timeout"
  | ОстановленоЧеловеком = "stopped_by_human"
  | ПотолокЗаходов = "ceiling_reached"
  | ОтмененоРодителем = "cancelled"
  | ПредельТокенов = "max_tokens"
  | ПредельЗапросовХода = "max_turn_requests"
тип ВидВызывающего перечисление Линза | СессияЦикла | ХодЧата | Вратарь
тип Критичность перечисление Критическая | Значимая | Желательная

тип ЗапросАгента { вид ВидВызывающего, профиль ПрофильАгента, сессия строка, вид_диалога строка, контекст строка,
                   пределы ПределыАгента, трасса строка, номер_шага число }
тип Использование { сессия строка, результат строка, семья строка, модель МодельАгента, токены Токены, стоимость ?вещественное,
                    создано число, обновлено число, занято_контекста ?число, трасса строка, номер_шага число }
тип ОтветАгента { текст ?строка, артефакт ?строка, использование Использование, начало_запроса ?число }
тип Находка { критичность Критичность, доказательство строка, повтор булево, вопрос булево }
тип Линза { идентификатор строка, потери_подряд число>=0, пробы число>=0, попытка число>=0 }
тип ИтогЛинзы { находки []Находка, пробы число>=0 }
тип КонтекстРоли перечисление
  | Линза { предложение строка, ответы_свидетеля ?[]ОтветСвидетеля }

  | СУтверждением { утверждение строка }
  | НеИзмерено { утверждение строка }
тип ИтогПравки перечисление
  | Закончена { предложение строка }
  | Вопрос { предложение строка, вопрос строка }
```

## Стороны

| имя | идентификатор | вид | профиль | сигналы | счётчик |
|---|---|---|---|---|---|
| свидетель | witness | machine шаг_агента(вход ЗапросАгента, итог ОтветАгента); разбор: разобрать_ответ_агента("witness") -> []ОтветСвидетеля | профиль_стороны("witness") | — | попытка_свидетеля |
| автор | author | machine шаг_агента(вход ЗапросАгента, итог ОтветАгента); разбор: разобрать_ответ_агента("author") -> ИтогПравки | профиль_стороны("author") | — | попытка_автора |
| линза | — | machine шаг_агента(вход ЗапросАгента, итог ОтветАгента); разбор: разобрать_ответ_агента("lens") -> ИтогЛинзы | профиль_стороны(сторона) | — | линзы[*].попытка |
| вратарь | gatekeeper | human или agent по настройке исполнитель_повышенного_внимания(итог ИсходВорот) | — | — | попытка_вратаря |
| усиленный | enhanced | enhanced(итог ИсходВорот) | — | продолжить { слово_человека строка, автор строка, источник строка }, остановить совещание | попытка_усиленного |

## Состояния

Начальное состояние: ПРАВКА

### ЛИНЗЫ — обращение
- Сторона: линза; набор: порядок_линз
- Срок тишины: 0
- Запрос:

| поле запроса | выражение | читает |
|---|---|---|
| вид | ВидВызывающего.Линза | сторона |
| сессия | сторона | сторона |
| вид_диалога | "main" | сторона |
| контекст | контекст_роли(КонтекстРоли.Линза { предложение: предложение, ответы_свидетеля: ответы_свидетеля[номер_захода] }) | сторона |
| пределы | ПределыАгента { срок_тишины: пусто, бюджет_токенов: пусто, бюджет_стоимости: пусто, предел_ходов: пусто } | сторона |
| трасса | — | сторона |
| номер_шага | — | сторона |
| номер_захода | — | исполнитель |
| к_отправке | — | исполнитель |
| линзы | — | исполнитель |
| ответившие | — | исполнитель |

- При приёме:

| событие | действия |
|---|---|
| ответ(итог) | { пусть л = обязательно(линзы[сторона]); линзы[сторона] = { ...л, потери_подряд: 0, пробы: итог.пробы } }; ответившие += 1; находки_линзы[(сторона, номер_захода)] = итог.находки |
| сбой | { пусть л = обязательно(линзы[сторона]); линзы[сторона] = { ...л, потери_подряд: л.потери_подряд + 1, пробы: 0 } } |

| № | Событие | Условие | Действия | Куда |
|---|---|---|---|---|
| 1 | ответ | — | — | КОНЕЦ |
| 2 | сбой | — | — | КОНЕЦ |

### ПРАВКА — обращение
- Сторона: автор
- Срок тишины: 0
- Правит: предложение; проверка: предложение_менялось_с_начала_попытки
- Возвратов формы: 2
- Запрос:

| поле запроса | выражение | читает |
|---|---|---|
| вид | ВидВызывающего.СессияЦикла | сторона |
| сессия | "author" | сторона |
| вид_диалога | "main" | сторона |
| контекст | контекст_роли(КонтекстРоли.Линза { предложение: предложение, ответы_свидетеля: пусто }) | сторона |
| пределы | ПределыАгента { срок_тишины: пусто, бюджет_токенов: пусто, бюджет_стоимости: пусто, предел_ходов: пусто } | сторона |
| трасса | — | сторона |
| номер_шага | — | сторона |

- При приёме:

| событие | действия |
|---|---|
| ответ: Закончена { предложение: правка } | предложение = правка |
| ответ: Вопрос { предложение: правка, вопрос: текст_вопроса } | предложение = правка; вопрос_автора = текст_вопроса |

| № | Событие | Условие | Действия | Куда |
|---|---|---|---|---|
| 1 | ответ: Закончена | — | указание_автору = "" | КОНЕЦ |
| 2 | ответ: Вопрос | — | указание_автору = "" | КОНЕЦ |
| 3 | сбой | — | — | КОНЕЦ |

### КОНЕЦ — конец
- Читает: предложение

### ОСТАНОВЛЕНО — конец
- Читает: остановка
- Кроме: остановка в [""]

## Концы

- Результат: строка

| конец | № | когда | ответ |
|---|---|---|---|
