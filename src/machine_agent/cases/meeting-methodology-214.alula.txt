# Машина: Совещание

- machine: meeting
- machine_version: alula-2.14
- format: 2.14

Это **запись машины «Совещание агентов» целиком на Алуле**, версия формата 2.14 ([state-machine-alula-spec.md](state-machine-alula-spec.md); он единственное определение языка записи). Источник правды — таблицы состояний [task-runner-meeting-states.md](task-runner-meeting-states.md) (первоисточник), код автомата [task-runner-meeting-automaton.md](task-runner-meeting-automaton.md) и псевдокод [task-runner-meeting-pseudocode.md](task-runner-meeting-pseudocode.md); при расхождении верны они, а этот файл правится вслед за ними. Фрагмент «Пауза» — [state-machine-pause-states.md](state-machine-pause-states.md), коды журнала — [state-machine-journal.md](state-machine-journal.md), имена — [state-machine-glossary.md](state-machine-glossary.md). Вложенная машина «Шаг агента» — [state-machine-agent-step.alula.md](state-machine-agent-step.alula.md). Справка к записи — что не уложилось в формат, неоднозначности спецификации, соответствие источнику — [task-runner-meeting.alula-notes.md](task-runner-meeting.alula-notes.md).

**Статус.** Эквивалентность этой записи автомату по журналу не проверялась: интерпретатор «Совещания» не гонялся, сценарии не сравнивались. Состояний 30 (развилок 9, операций 6, обращений 12, концов 3), из них ПАУЗА приносит подключение «Пауза»; в разделе «Состояния» объявлено 29. Строк переходов в разделе «Состояния» — 67, столько же в таблицах первоисточника (девять из них — строки `иначе` развилок, равные умолчанию: ЗАХОД, ОТКАЗ, ВСЕ_ЗАКРЫТЫ, ПОВТОР_ОБРАЩЕНИЯ, СВЕРКА, РАЗБОР, БЕЗ_ПРОБ, ИТОГ, ПОТОЛОК); строки ПАУЗА 1–4 и ОБЩ 1–6 приходят из фрагмента. Строк «Концов» 12: КОНЕЦ 1, ОШИБКА 1, ОСТАНОВЛЕНО 10 (шесть строк таблицы «конец → ответ» первоисточника, развёрнутые по значениям `остановка`).

**Как устроена запись.** Разделы идут в порядке раздела 1 формата. Номер `№` строки состояния равен метке `ИМЯ #n` в таблицах и в коде автомата (метка умолчания развилки — следующий номер). Строки-ключи состояний — элементы списка, таблицы стоят на уровне блока. Текстовые значения закрытых наборов (`остановка`, `сбойное_обращение`) — слова кода автомата (латиница). Имена, которые выходят из машины (состояния, данные, поля входа, типы, их поля, варианты и элементы, сигналы сторон и их поля, примитивы, имя настройки вратаря), несут латинское JSON-имя в скобках при объявлении (спецификация, раздел 1а, «JSON-имя»); JSON-имена — имена кода автомата (по словарю), у типов вызова «Шага агента» — те же, что в его образце; данные контракта (`остановка`, `к_отправке`) скобок не несут: их JSON-имя — слово таблицы слов. Коды журнала — по таблице [журнала](state-machine-journal.md). Тела функций без тела в источнике (`has_critical`, `merge_unique`, `build_summary`, `remove_unsound` и другие) записаны примитивами хозяина (раздел «Примитивы», спецификация, раздел 7).

- Предел запросов: ПРЕДЕЛ_ЗАПРОСОВ

Стороны вложенных вызовов — три: свидетель, автор, линза (набор по `порядок_линз`); все три — вложенная машина «Шаг агента». Профиль стороны — настройка проекта «Профили ролей», его читает примитив `профиль_стороны`. Вратарь — человек по умолчанию, агент по настройке проекта `исполнитель_повышенного_внимания` (ворота СБОЙ, ИЗМЕНЁН, ПОВТОР, В3, В9, В7, ПРИНЯТИЕ); усиленный — сторона состояния ПАУЗА (решение 12 первоисточника).

## Определения

```
определение пределы_роли() -> ПределыАгента =
  ПределыАгента { срок_тишины: если СРОК_БЕЗДЕЙСТВИЯ == 0 то пусто иначе СРОК_БЕЗДЕЙСТВИЯ, бюджет_токенов: пусто, бюджет_стоимости: пусто, предел_ходов: пусто }

определение слово_да_нет(б да/нет) -> текст =
  если б то "yes" иначе "no"
```

Соответствие коду автомата: `role_limits` — `пределы_роли`. `слово_да_нет` — для значений параметров журнала `repeat` и `question` (раздел 4.7 формата). `call_kind` кода записан значениями во «Входах» сторон: у линзы `ВидВызывающего.Линза`, у свидетеля и автора `ВидВызывающего.ХодЧата` (решение 2 первоисточника). `ceiling_reached` слоя методики — `потолок_исчерпан` из подключённого файла `арифметика_цикла`; `reset_origin` и `no_probes_step` слоя методики — строки таблиц (`заход_отсчёта = номер_захода`; условия БЕЗ_ПРОБ), определениями не служат.

### ПРИНЯТИЕ — обращение (Acceptance)
- Сторона: вратарь
- Запрос:

| поле запроса | выражение | читает |
|---|---|---|
| предложение | предложение | сторона |
| номер_захода | номер_захода | сторона |
| открытые | открытые | сторона |

| № | Событие | Условие | Действия | Куда |
|---|---|---|---|---|
| 1 | сигнал(подтвердил(подтверждение: слово_подтверждения)) | — | подтверждение = слово_подтверждения | КОНЕЦ |

Состояние ПАУЗА приносит подключение «Пауза» (раздел «Подключения»); оно здесь не объявляется, его строки ПАУЗА 1–4 и общие события ОБЩ 1–6 — в разделе 9 спецификации.

### ОСТАНОВЛЕНО — конец (Halted)
- Читает: остановка, открытые, находки_В3
- При входе:
  - вызвать(открыть_для_записи, "proposal");
  - журнал(meeting_stopped, reason: остановка);
  - для каждого н в открытые: журнал(unclosed_finding, severity: текст(н.критичность), evidence: н.доказательство, repeat: слово_да_нет(н.повтор), question: слово_да_нет(н.вопрос));
  - для каждого н в не_вошедшие_в(находки_В3, открытые): журнал(unclosed_finding, severity: текст(н.критичность), evidence: н.доказательство, repeat: слово_да_нет(н.повтор), question: слово_да_нет(н.вопрос))
- Кроме: остановка in {""}

### ОШИБКА — конец (Errored)
- Читает: все_данные
- При входе:
  - вызвать(открыть_для_записи, "proposal");
  - журнал(запись_перехода);
  - журнал(все_данные)

### КОНЕЦ — конец (End)
- Читает: предложение, подтверждение, номер_захода, открытые
- При входе:
  - вызвать(открыть_для_записи, "proposal");
  - журнал(meeting_decision, decision: предложение, source: подтверждение, passes: текст(номер_захода));
  - для каждого н в открытые: журнал(open_finding, severity: текст(н.критичность), evidence: н.доказательство, repeat: слово_да_нет(н.повтор), question: слово_да_нет(н.вопрос));
  - журнал(older_findings_in_pass_files)

В ОШИБКУ входят из «иначе» развилок (`ошибка_машины("fork_no_match", …)`), из ОБЩ 6 (`ошибка_машины("cancel_parse_no_match")`) и по ошибке машины исполнителя; на всех путях определено `запись_перехода`.
