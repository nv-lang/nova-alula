# Машина: Примеры формата

machine: FormatExamples
machine_version: 1
format: 2.23

> Примеры разделов 2–9 формата методики (версия 2.5), которые он называет целыми машинами или фрагментами и которых нет в пилоте «Шаг агента»: ворота В3,
> операции ЗАМОК, ВОЗВРАТ, ФИЛЬТР, СВОД, ОТКРЫТИЕ, развилки СВЕРКА и ОТКАЗ, концы «Совещания» и таблица «Концы», данные «Совещания», реестр примитивов.
> Тексты строк — как в формате. Вокруг них — минимальное окружение, чтобы файл загрузился: данные и типы, развилка ЗАХОД, которая ведёт во все примеры,
> и концы-заглушки для состояний, которых в примерах нет (ИТОГ, ЛИНЗЫ, АННУЛ, РАЗБОР, ИЗМЕНЁН, ВСЕ_ЗАКРЫТЫ, СБОЙ, ХОД_АГЕНТА).
> ЛИНЗЫ и ПРАВКА как целые состояния — в файле `unsupported-examples.alula.md` (сторона `machine` и `Правит` не поддержаны).

## Типы

```
тип КодСбоя перечисление
  | НетРезультата = "no_result"
  | ОтказМодели = "model_refused"
  | СоединениеОборвалось = "connection_lost"
  | ФормаНеИсправлена = "form_not_fixed"
  | НетОтветаВСрок = "timeout"
  | ОстановленоЧеловеком = "stopped_by_human"
  | ПотолокЗаходов = "ceiling_reached"
  | ОтмененоРодителем = "cancelled"
  | ПредельТокенов = "max_tokens"
  | ПредельЗапросовХода = "max_turn_requests"
тип Критичность перечисление Критическая | Значимая | Желательная
тип Находка { критичность Критичность, доказательство строка, повтор булево, вопрос булево }
тип Линза { идентификатор строка, потери_подряд число>=0, пробы число>=0, попытка число>=0 }
тип Свод { пробы число>=0 }
тип ИтогСовещания { решение строка, источник строка, число_заходов число>=1, открытые []Находка }
```

## Функции

```
функция слово_да_нет(б булево) -> строка =>
  если б то { "yes" } иначе { "no" }

функция не_вошедшие_в(находки []Находка, среди []Находка) -> []Находка =>
  находки.фильтр(н => не среди.любой(с => с.доказательство == н.доказательство))
```

## Состояния

Начальное состояние: ЗАХОД

### ЗАХОД — развилка
Читает: номер_захода

| № | Условие | Действия | Куда |
|---|---|---|---|
| 1 | номер_захода == 1 | — | В3 |
| 2 | номер_захода == 2 | — | ЗАМОК |
| 3 | номер_захода == 3 | — | ВОЗВРАТ |
| 4 | номер_захода == 4 | — | ФИЛЬТР |
| 5 | номер_захода == 5 | — | СВЕРКА |
| 6 | номер_захода == 6 | — | ОТКАЗ |
| 7 | номер_захода == 7 | — | ОТКРЫТИЕ |
| 8 | номер_захода == 8 | — | ОСТАНОВЛЕНО |
| 9 | иначе | — | КОНЕЦ |

### В3 — обращение
Сторона: вратарь
Запрос:

| поле запроса | выражение | читает |
|---|---|---|
| номер_захода | — | исполнитель |
| находки_В3 | — | исполнитель |

| № | Событие | Условие | Действия | Куда |
|---|---|---|---|---|
| 1 | сигнал(не засчитан) | — | журнал("pass_probes_not_probes", pass: строка(номер_захода)); номер_захода += 1 | ЗАХОД |
| 2 | сигнал(засчитан { находки: новые }) | — | номер_захода += 1; находки_В3 = новые | ИТОГ |

### ЗАМОК — операция
Читает: предложение, порядок_линз
При входе: пусть отпечаток = отпечаток_предложения(); закрыть_для_записи("proposal")

| № | Событие | Условие | Действия | Куда |
|---|---|---|---|---|
| 1 | сразу | — | копия = предложение; отпечаток_копии = отпечаток; к_отправке = порядок_линз; ответившие = 0 | ЛИНЗЫ |

### ВОЗВРАТ — операция
Читает: копия

| № | Событие | Условие | Действия | Куда |
|---|---|---|---|---|
| 1 | сразу | — | если есть(копия) то { предложение = обязательно(копия) } иначе { журнал("copy_restore_no_copy") } | АННУЛ |

### ФИЛЬТР — операция
Читает: номер_захода, порядок_линз, находки_линзы, ответы_свидетеля, линзы
При входе: убрать_несостоятельные(номер_захода);
           пусть без_критических = линзы_без_критических()

| № | Событие | Условие | Действия | Куда |
|---|---|---|---|---|
| 1 | сразу | — | для л из без_критических { линзы[л] = { ...обязательно(линзы[л]), пробы: 0 } } | СВОД |

### СВОД — операция
Читает: номер_захода, порядок_линз, находки_линзы, линзы
При входе: пусть итог = собрать_свод(номер_захода)

| № | Событие | Условие | Действия | Куда |
|---|---|---|---|---|
| 1 | сразу | — | если есть(итог) то { свод[номер_захода] = обязательно(итог) } | РАЗБОР |

### СВЕРКА — развилка
Читает: отпечаток_копии
При входе: пусть прочитано = предложение_прочитано();
           пусть отпечаток = если прочитано то { отпечаток_предложения() } иначе { пусто }

| № | Условие | Действия | Куда |
|---|---|---|---|
| 1 | прочитано и отпечаток == отпечаток_копии | — | ФИЛЬТР |
| 2 | прочитано и отпечаток != отпечаток_копии | — | ИЗМЕНЁН |
| 3 | не прочитано | — | ИЗМЕНЁН |
| 4 | иначе | ошибка_машины("fork_no_match", fork: "Comparison") | — |

### ОТКАЗ — развилка
Читает: линзы, к_отправке, номер_захода

| № | Условие | Действия | Куда |
|---|---|---|---|
| 1 | обязательно(линзы[событие.сторона]).потери_подряд == 1 | журнал("lens_dropped", party: событие.сторона, pass: строка(номер_захода)) | ВСЕ_ЗАКРЫТЫ |
| 2 | обязательно(линзы[событие.сторона]).потери_подряд == 2 | сбойное_обращение = "Lenses"; к_отправке = [событие.сторона] + к_отправке | СБОЙ |
| 3 | иначе | ошибка_машины("fork_no_match", fork: "LensRefusal") | — |

### ОТКРЫТИЕ — операция
При входе: пусть новая = новый_ид()

| № | Событие | Условие | Действия | Куда |

| 1 | сразу | — | ид_сессии = новая | ХОД_АГЕНТА |

### ОСТАНОВЛЕНО — конец
Читает: остановка, открытые, находки_В3
При входе: открыть_для_записи("proposal");
           журнал("meeting_stopped", reason: остановка);
           для н из открытые { журнал("unclosed_finding", severity: строка(н.критичность), evidence: н.доказательство, repeat: слово_да_нет(н.повтор), question: слово_да_нет(н.вопрос)) };
           для н из не_вошедшие_в(находки_В3, открытые) { журнал("unclosed_finding", severity: строка(н.критичность), evidence: н.доказательство, repeat: слово_да_нет(н.повтор), question: слово_да_нет(н.вопрос)) }
