# Библиотека: Пауза

- library: pause
- format: 2.26

## Параметры

| имя | тип | комментарий |
|---|---|---|
| сигнал_остановки | строка | сигнал стороны «усиленный», по которому машина останавливается |
| вложенные | []строка | имена машин, которым идут сигналы цепочки (правило 35, пункт 8) |
| отмена_запросов | "механика" \| "без_возврата_в_к_отправке" \| "прекратить_ход_транспорта" | эффекты — таблица раздела 9 спецификации |
| вход_заново | "ничего" \| "запросы_из_к_отправке" | эффекты — таблица раздела 9 спецификации |

## Требует

| имя | тип |
|---|---|
| усиленный | сторона enhanced с сигналами продолжить { слово_человека строка, автор строка, источник строка } и сигнал_остановки |
| ОСТАНОВЛЕНО | конец |
| ОШИБКА | конец |

## Типы

```
тип ПричинаПаузы перечисление
  | Остановлена = "pause_halt"
  | Отменена = "cancel_request"
```

## Имена

| имя | JSON-имя |
|---|---|
| ПричинаПаузы | PauseReason |
| Остановлена | Halted |
| Отменена | Cancelled |

## Данные

| имя | тип | начальное |
|---|---|---|
| предыдущее | ?Состояние | пусто |
| причина | ?ПричинаПаузы | пусто |

## Общие события     // разбираются до строк состояний (правило 23)

| Событие | Условие | Действия | Куда |
|---|---|---|---|
| сигнал(стоп человека { слово_человека, автор, источник }) | не конец(состояние) и состояние != ПАУЗА | журнал("human_stop", author: автор, source: источник, event: событие.идентификатор)<br>предыдущее = состояние<br>передать(вложенные, стоп)<br>отменить_открытые(кроме: вложенные) | ПАУЗА |
| сигнал(стоп от родителя { идентификатор_запроса }) | не конец(состояние) и состояние != ПАУЗА и идентификатор_запроса == запрос_вызова | журнал("pause_by_parent_stop", request: идентификатор_запроса, event: событие.идентификатор)<br>предыдущее = состояние<br>передать(вложенные, стоп)<br>отменить_открытые(кроме: вложенные) | ПАУЗА |
| сигнал(отмена_запроса { идентификатор_запроса }) | идентификатор_запроса != запрос_вызова | журнал("cancel_discarded_foreign_request", request: идентификатор_запроса, event: событие.идентификатор) | то же |
| сигнал(отмена_запроса { идентификатор_запроса }) | идентификатор_запроса == запрос_вызова и конец(состояние) | журнал("cancel_discarded_already_replied", request: идентификатор_запроса, event: событие.идентификатор) | то же |
| сигнал(отмена_запроса { идентификатор_запроса }) | идентификатор_запроса == запрос_вызова и не конец(состояние) | журнал("request_cancelled", request: идентификатор_запроса, event: событие.идентификатор)<br>причина = ПричинаПаузы.Отменена<br>передать(вложенные, отмена)<br>отменить_открытые | ОСТАНОВЛЕНО |
| сигнал(отмена_запроса { идентификатор_запроса }) | иначе | ошибка_машины("cancel_parse_no_match") |  |

## Состояния

### ПАУЗА — обращение
- Сторона: усиленный
- Запрос:

| поле запроса | выражение |
|---|---|
| предыдущее | обязательно(предыдущее) |
| запрос_вызова |  |

| Событие | Условие | Действия | Куда |
|---|---|---|---|
| сигнал(продолжить { автор, источник }) |  | журнал("human_continue", previous: строка(обязательно(предыдущее)), author: автор, source: источник, event: событие.идентификатор)<br>передать(вложенные, продолжить) | предыдущее |
| сигнал(сигнал_остановки) |  | причина = ПричинаПаузы.Остановлена<br>передать(вложенные, остановить) | ОСТАНОВЛЕНО |
| сигнал(продолжить от родителя { идентификатор_запроса }) | идентификатор_запроса == запрос_вызова | журнал("parent_continue", previous: строка(обязательно(предыдущее)), request: идентификатор_запроса, event: событие.идентификатор)<br>передать(вложенные, продолжить) | предыдущее |
| сигнал(остановить от родителя { идентификатор_запроса }) | идентификатор_запроса == запрос_вызова | причина = ПричинаПаузы.Остановлена<br>передать(вложенные, остановить) | ОСТАНОВЛЕНО |
