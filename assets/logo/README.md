# Логотип Алулы

Знак: плашка с сеткой 3×3 состояний, диагональ — путь по переходам, конечное состояние в углу нарисовано пером (alula — «крылышко», маленькое перо на крыле птицы). Цвет `#1D9E75`.

| Файл | Где |
|---|---|
| `alula-mark.svg` | основной знак: документация, аватар репозитория (от 48 px) |
| `alula-mark-small.svg` | значки 16–32 px: сетка без пера |
| `alula-feather.svg` | отдельное перо на плашке |
| `alula-wordmark-light.svg`, `alula-wordmark-dark.svg` | знак со словом «Алула» для светлого и тёмного фона |
| `alula-wordmark-light-en.svg`, `alula-wordmark-dark-en.svg` | то же со словом «Alula» |
| `alula-wordmark-mono-light.svg`, `alula-wordmark-mono-dark.svg` | знак со словом «Алула» моноширинным шрифтом (JetBrains Mono 700): для мест, связанных с кодом, имён пакетов и README репозитория |
| `alula-wordmark-mono-light-en.svg`, `alula-wordmark-mono-dark-en.svg` | то же со словом «alula» строчными |

Слово во всех файлах со словом переведено в кривые (форма букв Manrope 700 в обычных файлах и JetBrains Mono 700 в файлах `mono`; оба шрифта открытые, лицензия OFL, шрифты в репозиторий не входят), от шрифтов на машине файлы не зависят. Первоисточник — эта папка.
