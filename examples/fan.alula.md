# Машина: Веер

- machine: fan
- machine_version: 1
- format: 2.26

Набор вложенных вызовов (задача 119): по запросу к `callee` на каждый идентификатор из входа `order` («линзы» совещания), не больше `LIMIT` одновременно (`Предел запросов`). Каждый элемент набора считает свои попытки в записи `lenses[элемент].attempt` (счётчик `lenses[*].attempt`), запрос — `<элемент>-<попытка>`. Ответ или отказ элемента записывается в `answered` или `lost`, развилка JOIN возвращает в обращение, пока не ответили все. Стороны, которым запрос ещё не ушёл, лежат в `to_send`; после паузы (библиотека «Пауза» со списком вложенных `[callee]`, `вход_заново: запросы_из_к_отправке`) они уходят из `to_send`.

## Типы

```
тип Lens { name строка, attempt число>=0 }
тип LensInput { label строка, count число>=0, profile строка }
тип CallOutput { answer строка, score число>=0 }
```
