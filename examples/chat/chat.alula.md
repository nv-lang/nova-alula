# Машина: Сеанс чата с агентом

- machine: ChatSession
- revision: 1
- alula_version: 0.27

> Демо-машина: одна беседа пользователя с агентом, формат 0.27. Перевод даёт JSON, равный по поведению рукописному `chat.alula.json` (у рукописного дерева — латинские внутренние имена).
> Часть ответа — тип `КусокОтвета` в столбце `части` агента, срок тишины отсчитывается заново на каждой части (библиотека `контракт` языка). Отмена — сигнал протокола вызова `отмена_запроса`
> (`cancel_request`) в общих событиях машины: в 0.27 сигнал машины объявляет подключённая библиотека, это `libs/call_cancel.alula.md`.

## Типы

```
тип КусокОтвета { содержание строка }
```

## Имена

| имя | JSON-имя |
|---|---|
| реплика_пользователя | user |
| реплика_агента | reply |
| код_отказа | stop_code |
| текст_отказа | stop_text |
| сообщение_пользователя | user_message |
| содержание | content |
| ПОКОЙ | Idle |
| ОЖИДАНИЕ | Awaiting |
| ГОТОВО | Done |
| ОТКАЗ | Failed |
| КусокОтвета | agent_chunk |

## Константы

| имя | тип | значение |
|---|---|---|
| СРОК_БЕЗДЕЙСТВИЯ | число>=0 | 30000 |

## Данные

| имя | тип | начальное | не убывает |
|---|---|---|---|
| реплика_пользователя | строка | "" | — |
| реплика_агента | строка | "" | — |
| код_отказа | ?КодСбоя | пусто | — |
| текст_отказа | строка | "" | — |

## Стороны

| имя | идентификатор | вид | профиль | сигналы | части | счётчик |
|---|---|---|---|---|---|---|
| пользователь | user | human(итог ИсходВорот) | — | сообщение_пользователя { содержание строка } | — | — |
| агент | agent | agent(итог строка) | — | — | КусокОтвета | попытка_агента |

|---|---|---|---|
