# Журнал примера chat: коды машины беседы с агентом

Данные хозяина примера (7 кодов машины `chat`): программа берёт их из папки машины (`alula test examples/chat`). Те же коды есть в журнале примеров (`../journal.md`), чтобы `alula test examples` читал и эту папку. Код примера не повторяет код языка. Форма: `Машина | Код события | Русский шаблон | Параметры`.

| Машина | Код события | Русский шаблон | Параметры |
|---|---|---|---|
| чат | `agent_chunk` | часть ответа агента: {text} | `text` |
| чат | `agent_done` | агент закончил ответ | — |
| чат | `agent_refused` | агент отказал: {code} | `code` |
| чат | `cancelled_before_request` | отмена до запроса | — |
| чат | `cancelled_while_waiting` | отмена в ожидании ответа | — |
| чат | `no_answer_in_time` | ответа в срок нет | — |
| чат | `user_message` | сообщение пользователя: {text} | `text` |
