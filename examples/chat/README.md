# chat: демо-машина беседы с агентом

Демо-машина: одна беседа с агентом. Пользователь пишет одно сообщение, машина посылает агенту запрос и ждёт ответа; ответ приходит частями и кончается итогом.
Пять исходов беседы:

| Исход | Что происходит | Куда |
|---|---|---|
| ожидание | `ПОКОЙ` → `ОЖИДАНИЕ` по сигналу `сообщение_пользователя`: запрос агенту, части ответа (`часть`) копятся в `реплика_агента` | `ОЖИДАНИЕ` |
| ответ | агент закончил ответ (`ответ`) | `ГОТОВО`, итог `Ответ(реплика_агента)` |
| отказ | агент отказал (`сбой(код)`): код сбоя языка в `код_отказа` | `ОТКАЗ` |
| отмена | сигнал `отмена_запроса` в покое или в ожидании (общие события; в ожидании открытый запрос отменяется) | `ОТКАЗ`, `ОстановленоЧеловеком` |
| таймаут | нет ни части, ни ответа за срок тишины `СРОК_БЕЗДЕЙСТВИЯ` (30 000 мс; каждая часть отсчитывает его заново) | `ОТКАЗ`, `НетОтветаВСрок` |

| Файл | Что в нём |
|---|---|
| `chat.alula.md` | таблица машины `ChatSession`, формат 0.27 |
| `chat.alula.json` | рукописное дерево той же машины (латинские внутренние имена), равное переводу таблицы по поведению |
| `libs/call_cancel.alula.md` | библиотека «Отмена запроса»: объявляет сигнал протокола вызова `отмена_запроса` (`cancel_request`), который берут общие события машины |
| `journal.md` | 7 кодов журнала машины (хозяин примера) |
| `tests/chat-*.alula.test.json` | 39 проверок (`test/0`): ожидание и части, ответ, отказы по каждому коду сбоя, отмена, таймаут, перезапуски, лишние и чужие события |
